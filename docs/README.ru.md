# AnimeStage

**Превратите рабочий стол KDE Plasma 6 в любимое аниме.**
Введите название аниме – AnimeStage построит вокруг него весь рабочий стол: сменяющиеся обои, подходящие цвета везде, персонажи в меню запуска, терминал, Firefox и VS Code в стиле темы.

## Возможности

- **Любое аниме** – поиск через AniList; название, баннер и персонажи (с возрастом) загружаются автоматически.
- **Сменяющиеся обои** – новые изображения с Konachan каждые 2 часа (настраивается), по персонажу, фильтру и настроению. Сохраняйте избранное или отбраковывайте изображения.
- **Цвета следуют за обоями** – акцентные цвета каждого нового изображения применяются к Plasma, оформлению окон, значкам (папки Papirus), терминалу, Firefox и VS Code.
- **Панель в стиле аниме** – меню запуска с вырезкой персонажа, панель задач с заголовками окон, музыкальная «пилюля», кольца CPU/RAM/GPU и календарь.
- **Терминал** – kitty или Konsole в цветах темы, приветствие с новым изображением и сведениями о системе, приглашение Starship и при желании изображение на фоне терминала.
- **Firefox** – вкладки и адресная строка в подходящих цветах, плюс изображение на новой вкладке, которое меняется при каждом запуске.
- **Экран блокировки и экран входа** тоже показывают ваши обои (вход: Plasma Login Manager).
- **Центр управления** – всё в одном окне, без правки конфигурационных файлов.
- **13 языков** – следует языку системы, переключается в Центре управления.

### Панель задач как в Windows

![Панель задач с названиями окон](screenshots/taskbar.png)

Каждое окно получает свою кнопку с названием рядом со значком – два окна Firefox дают две кнопки. Закреплённые программы остаются на своих местах, и их окна открываются там же. В **Центр управления → Внешний вид → Панель задач** можно скрыть названия, группировать окна или выбрать ширину (узкая / средняя / широкая).

![Три варианта обоев, у каждого – цвета, которые AnimeStage из него берёт](screenshots/wallpapers.jpg)

Каждые новые обои приносят свои цвета: AnimeStage берёт из изображения акцентный и фоновый цвета и перекрашивает панель, окна, значки, терминал, Firefox и VS Code – автоматически каждые 2 часа. Панель внизу каждой картинки показывает цвета именно этого изображения.

## Требования

- **KDE Plasma 6** (создано и проверено на Bazzite / Fedora Atomic с Plasma 6.8; другие дистрибутивы с Plasma 6 тоже должны работать)
- Python 3 с **Pillow** (`python3-pillow`)
- Подключение к интернету (AniList, Konachan, Danbooru)
- Необязательно: kitty (устанавливается автоматически по запросу), Homebrew для Starship/eza/bat/zoxide, Kvantum

Всё устанавливается в ваш профиль пользователя – **права root не нужны**. Только обои экрана входа один раз попросят пароль.

## Установка

**Простой способ (рекомендуется):**

1. Скачайте **AnimeStage.zip** из [последнего релиза](https://github.com/propanisen/AnimeStage/releases/latest).
2. Распакуйте (правый щелчок → *Распаковать сюда*).
3. Дважды щёлкните **Установить AnimeStage** в папке и следуйте окнам: язык, панель, аниме – готово.

**Одна строка в терминале:**

```bash
curl -fsSL https://github.com/propanisen/AnimeStage/releases/latest/download/get.sh | bash
```

**Через git (для разработчиков):**

```bash
git clone https://github.com/propanisen/AnimeStage.git
cd AnimeStage
./install.sh --plan          # показать, что произойдёт (ничего не меняет)
./install.sh                 # установить (сначала создаётся резервная копия настроек KDE)
```

Параметры:

```bash
./install.sh --anime "Frieren"   # сразу начать с аниме
./install.sh --lang ru           # язык установщика и темы
./install.sh --profile core      # оставить текущую панель
```

Затем откройте **Меню запуска → Центр управления AnimeStage → Аниме** и найдите своё аниме.

### Обновление

AnimeStage раз в день проверяет на GitHub, вышла ли новая версия, и показывает уведомление. Установить её можно одним щелчком в **Центр управления → Система → Updates** (или `animestage update install`). В уведомлении есть кнопка **Установить сейчас** – или обновления могут устанавливаться сами (настройка там же). Перед каждым обновлением создаётся резервная копия. Не нужна проверка? Снимите там галочку или выполните `animestage update off`.

Обновление вручную из git-клона:

```bash
git pull
./update.sh          # настройки, избранное и панель останутся как есть
```

### Удаление

**Простой способ:** Центр управления → Система → **Удалить AnimeStage …** – окно сначала спросит и всё восстановит.

**В терминале:**

```bash
./uninstall.sh            # удаляет всё и восстанавливает исходные настройки KDE
./uninstall.sh --purge    # также удаляет загруженные изображения и настройки
```

**Что происходит при установке и удалении:** прежде чем что-либо менять, установщик сохраняет ваши настройки KDE (панель, цвета, оформление окон, шрифты, экран блокировки, заставку …) в `~/.local/state/animestage/backups/original`. При удалении стираются все файлы и таймеры AnimeStage, отменяются изменения терминала, Firefox, VS Code и экрана входа, а затем восстанавливается эта копия – рабочий стол выглядит точно как раньше. Изменения панели, сделанные после установки, тоже сбрасываются. Сами резервные копии сохраняются.

## Фильтр контента

AnimeStage **по умолчанию безопасен** (фильтр «Строго»).

- **SFW** показывает всех персонажей аниме.
- **Ecchi / NSFW** можно включить, но он **показывает только совершеннолетних персонажей**: возраст должен быть указан в AniList (18+), либо вы отмечаете персонажа сами – это возможно, только если AniList не указывает возраст или указывает фэнтезийный, например «1000+». Персонажей, несовершеннолетних по данным AniList, разблокировать нельзя никогда.
- Откровенные изображения используются, только если на изображении нет других персонажей и ни один тег не указывает на кого-то младше.
- **Экран блокировки, экран входа, терминал и Firefox всегда показывают только изображения «safe».**
- Эти правила проверяет самотест; установщик отказывается устанавливать, если их удалили или ослабили.

Можно также показывать **только женских персонажей** (Центр управления → Аниме).

## Командная строка

```bash
animestage search frieren            # поиск в AniList
animestage anime 154587 --apply      # выбрать аниме
animestage wall next | fav | ban     # следующие обои, в избранное, больше не показывать
animestage set wallswitch.minutes 60 # интервал смены
animestage themed new terminal --tags "night, city"   # свой поиск для фона терминала
animestage source check              # доступны ли сайты с изображениями?
animestage status
animestage --help
```

## Источники изображений и свои источники

Весь поиск и загрузка изображений находятся в одном файле: [`lib/animestage_sources.py`](../lib/animestage_sources.py).
Если сайт перестал работать или нужен другой, добавьте его туда (`SOURCES` и `PURPOSES`) и запустите `./update.sh` – он появится в Центре управления в разделе **Система → Источники изображений**. Готовые адаптеры есть для Moebooru (Konachan, yande.re), Danbooru и сайтов в стиле Gelbooru.

## Переводы

Переводы лежат в [`i18n/`](../i18n/) – один JSON-файл на язык, немецкий исходный текст → перевод.
`tools/i18n-extract.py` показывает недостающие тексты. Исправления и новые языки очень приветствуются!
