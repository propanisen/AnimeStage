# AnimeStage

**Рабочий стол KDE Plasma 6 в стиле вашего любимого аниме.**
Введите название аниме — и AnimeStage оформит вокруг него весь рабочий стол: меняющиеся обои, подходящие цвета повсюду, персонажи в меню запуска, а также терминал, Firefox и VS Code в том же стиле.

## Возможности

- **Любое аниме** — поиск через AniList; название, баннер и персонажи (с возрастом) подтягиваются автоматически.
- **Меняющиеся обои** — каждые 2 часа (можно изменить) новые изображения с Konachan с учётом персонажа, фильтра и настроения. Понравившиеся можно сохранить, неподходящие — отклонить.
- **Цвета подстраиваются под обои** — из каждого нового изображения берутся акцентные цвета для Plasma, оформления окон, значков папок (Papirus), терминала, Firefox и VS Code.
- **Панель в стиле аниме** — меню запуска с персонажем, панель задач с названиями окон как в Windows, музыкальный плеер, кольца CPU/RAM/GPU и календарь.
- **Терминал** — kitty или Konsole в цветах темы, приветствие со свежим изображением и сведениями о системе, приглашение Starship и, по желанию, изображение на фоне.
- **Firefox** — вкладки и адресная строка в подходящих цветах, а при каждом запуске — новое изображение на странице новой вкладки.
- **Экран блокировки и экран входа** тоже показывают ваши обои (экран входа: Plasma Login Manager).
- **Центр управления** — всё настраивается в одном окне, без правки конфигурационных файлов.
- **13 языков** — следует языку системы, переключается в Центре управления.

### Панель задач как в Windows

![Панель задач с названиями окон](screenshots/taskbar.png)

У каждого окна своя кнопка с названием рядом со значком — два окна Firefox дают две кнопки. Закреплённые приложения остаются на своих местах, и их окна открываются там же. В разделе **Центр управления → Внешний вид → Панель задач** можно скрыть названия, группировать окна или выбрать ширину (узкие / средние / широкие).

## Требования

- **KDE Plasma 6** (разрабатывается и проверяется на Bazzite / Fedora Atomic с Plasma 6.8; другие дистрибутивы с Plasma 6 тоже должны подойти)
- Python 3 с **Pillow** (`python3-pillow`)
- Подключение к интернету (AniList, Konachan, Danbooru)
- Необязательно: kitty (при желании устанавливается автоматически), Homebrew для Starship/eza/bat/zoxide, Kvantum

Всё устанавливается в ваш профиль пользователя — **права root не нужны**. Только для обоев экрана входа один раз понадобится пароль.

## Установка

**Простой способ (рекомендуется):**

1. Скачайте **AnimeStage.zip** из [последнего релиза](https://github.com/propanisen/AnimeStage/releases/latest).
2. Распакуйте архив (правый щелчок → *Распаковать сюда*).
3. Дважды щёлкните в папке **Установить AnimeStage** и следуйте окнам: язык, панель, аниме — готово.

**Одной строкой в терминале:**

```bash
curl -fsSL https://github.com/propanisen/AnimeStage/releases/latest/download/get.sh | bash
```

**Через git (для разработчиков):**

```bash
git clone https://github.com/propanisen/AnimeStage.git
cd AnimeStage
./install.sh --plan          # показывает, что будет сделано (ничего не меняет)
./install.sh                 # установка (сначала создаётся резервная копия настроек KDE)
```

Параметры:

```bash
./install.sh --anime "Frieren"   # сразу начать с выбранного аниме
./install.sh --lang ru           # язык установщика и темы
./install.sh --profile core      # оставить текущую панель
```

Затем откройте **Меню запуска → Центр управления AnimeStage → Аниме** и найдите своё аниме.

### Обновление

Раз в день AnimeStage проверяет на GitHub, не вышла ли новая версия, и сообщает об этом уведомлением. Достаточно нажать **Установить сейчас** — или воспользоваться разделом **Центр управления → Система → Updates** либо командой `animestage update install`. Там же можно включить автоматическую установку обновлений. Перед каждым обновлением создаётся резервная копия. Проверка не нужна? Выберите там «Выключено» или выполните `animestage update off`.

Обновление вручную из git-клона:

```bash
git pull
./update.sh          # настройки, избранное и панель остаются как есть
```

### Удаление

**Простой способ:** Центр управления → Система → **Удалить AnimeStage…** — окно попросит подтверждения и всё восстановит.

**В терминале:**

```bash
./uninstall.sh            # удаляет всё и восстанавливает исходные настройки KDE
./uninstall.sh --purge    # дополнительно удаляет загруженные изображения и настройки
```

**Что происходит при установке и удалении:** прежде чем что-либо менять, установщик сохраняет настройки KDE (панель, цвета, оформление окон, шрифты, экран блокировки, заставку…) в `~/.local/state/animestage/backups/original`. При удалении стираются все файлы и таймеры AnimeStage, отменяются изменения в терминале, Firefox, VS Code и на экране входа, а затем восстанавливается эта копия — рабочий стол выглядит точно так же, как до установки. Изменения панели, сделанные после установки, тоже отменяются. Сами резервные копии сохраняются.

## Фильтр содержимого

AnimeStage **по умолчанию подходит для всех возрастов** (фильтр «Строгий»).

- **SFW** показывает всех персонажей аниме.
- **Ecchi / NSFW** можно включить, но он **показывает только совершеннолетних персонажей**: возраст должен быть указан в AniList (18+) или отмечен вами — а отметить можно, только если в AniList возраста нет или указан лишь фантастический вроде «1000+». Персонажей, которые по данным AniList несовершеннолетние, разблокировать нельзя никогда.
- Откровенные изображения используются, только если на них нет других персонажей и ни один тег не указывает на кого-то младше.
- **Экран блокировки, экран входа, терминал и Firefox всегда показывают только изображения «safe».**
- Эти правила проверяет самотест; если их удалили или ослабили, установщик отказывается устанавливать.

Можно также показывать **только женских персонажей** (Центр управления → Аниме).

## Командная строка

```bash
animestage search frieren            # поиск на AniList
animestage anime 154587 --apply      # выбрать аниме
animestage wall next | fav | ban     # следующие обои, в избранное, больше не показывать
animestage set wallswitch.minutes 60 # интервал смены
animestage themed new terminal --tags "night, city"   # свой поиск для фона терминала
animestage source check              # доступны ли сайты с изображениями?
animestage status
animestage --help
```

## Источники изображений и добавление своих

Весь поиск и загрузка изображений собраны в одном файле: [`lib/animestage_sources.py`](../lib/animestage_sources.py).
Если сайт перестал работать или хочется использовать другой, добавьте его туда (`SOURCES` и `PURPOSES`) и запустите `./update.sh` — он появится в Центре управления в разделе **Система → Источники изображений**. Готовые адаптеры есть для сайтов типа Moebooru (Konachan, yande.re), Danbooru и Gelbooru.

## Переводы

Переводы лежат в [`i18n/`](../i18n/) — по одному JSON-файлу на язык (исходный текст на немецком → перевод).
`tools/i18n-extract.py` показывает недостающие строки. Исправления и новые языки очень приветствуются!
